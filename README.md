# 镜间

中英双语电影视觉语言与美学分析网站。当前六部电影、人物、主创信息与 200 张图片均为网站功能演示而创作的虚构内容，不对应真实影片或演员。内容层包含 6 个分析维度、36 个视觉词条、36 个词条详情页和 12 篇美学专题。

## 运行

需要 Node.js 20.9 或更高版本，推荐使用 pnpm。

```bash
pnpm install
pnpm dev
```

访问 `http://localhost:3000`，默认进入中文站。中文与英文路径分别为 `/zh/...` 和 `/en/...`，顶部“中 / EN”可在保留当前页面和查询条件的情况下切换语言。正式检查：

```bash
pnpm typecheck
pnpm lint
pnpm build
pnpm start
```

## 内容结构

- `app/[lang]/[[...slug]]/`：中英文页面分发，包括首页、探索、电影、画面、专题、视觉词条、对比、灵感板和版权页面。
- `components/`：双语导航、卡片、筛选、画面标注、对比、收藏、色卡与版权组件。
- `lib/data.ts`：六部作品、既有画面、12 篇专题及筛选项。
- `lib/i18n.ts`：中英文界面、内容本地化、结构化读图、相似理由与画面标注数据。
- `lib/extended-frames.ts`：新增 30 个画面的完整视觉分析与版权数据。
- `lib/types.ts`：内容、版权、筛选和灵感板的公共类型。
- `public/images/frames/`：原创演示画面。
- `docs/image-prompts.md`：首批 50 张原创演示图的制作与审核记录。
- `docs/cinematic-expansion.md`：新增 150 张摄影技法画面的制作规范与清单。

视觉语言索引位于 `/zh/visual-index` 与 `/en/visual-index`。每个词条拥有独立详情页，包含定义、视觉作用、常见误读、观看提示、筛选入口和 6–12 个相关画面；新增术语时同步维护 `lib/visual-index.ts` 与 `lib/i18n.ts`。

## 探索、标注与对比

- 探索页默认跨作品混排，每次渲染 30 张；搜索、排序、筛选与加载数量保存在 URL。
- 同一分类内采用任一匹配，不同分类间采用同时匹配。
- 排序支持精选混排、最新作品、暖色情感、光影技巧和人物互动。
- 每张画面详情提供构图、光线和人物关系标注层，标注数据采用相对坐标，不修改原图。
- 对比工具最多容纳 4 张画面，并通过 `?frames=id1,id2` 形成可分享链接。

新增内容时先扩展 `lib/data.ts`，再把图片放入 `public/images/frames/`。图片必须保持原始宽高比，填写可描述画面内容的替代文字，并在电影、画面和专题之间使用稳定 slug 关联。

## 收藏

灵感板保存在浏览器 `localStorage` 的 `jingjian:boards:v1` 键中，结构为 `{ version, boards, activeBoardId }`。只保存画面 ID，不保存或复制图片；切换语言不会迁移或清空灵感板。清理浏览器数据会删除收藏。

## 图片版权要求

每张公开图片必须保存：图片标题、作者、权利人、来源链接、来源类型、授权类型、版权状态、使用范围、是否允许下载、授权证明编号或备注、添加日期与审核状态。

版权状态只能为：

- 本站原创
- 已获授权
- 公有领域
- 开放许可
- 待版权审核

只有“审核通过”且不是“待版权审核”的图片可以出现在 `publicFrames`。不得录入“来源不明”“网络素材”“侵删”等状态；未经明确授权不得使用真实电影截图、海报、演员照片或受保护标志。开放许可内容必须记录具体许可名称和可访问的许可链接。

当前图片标记为“镜间原创演示资产”，仅用于本站功能演示和美学分析，不提供原图下载，也不构成商业素材授权。替换图片时必须同步更新版权记录并保留授权证明。

## 版权邮箱与上线检查

默认邮箱 `rights@jingjian.example` 是不可收件的演示地址。正式上线前设置：

```bash
NEXT_PUBLIC_RIGHTS_EMAIL=rights@your-real-domain.com
```

上线前还必须：

- 验证版权邮箱真实可收件。
- 将权利人表单接入安全的邮件或工单后端，并提供隐私说明和文件上传保护。
- 复核所有图片授权状态、来源链接与许可范围。
- 确认待审核内容不会进入生产数据。
- 检查页面不存在图片下载入口或商业使用暗示。
